# Original miniatures

The cat-and-keyboard and orbiting-planet vector miniatures are original artwork created for this profile. No Sweezy files, character designs, or animation frames are included. Sweezy (https://sweezy-cursors.com/) was a general reference for playful personalization, not an asset source.

Animation is self-contained CSS inside SVG image assets, with a static fallback and prefers-reduced-motion handling. There is no JavaScript, tracking, external image request, cursor override, or browser extension.
