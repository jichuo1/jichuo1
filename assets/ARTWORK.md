# Original miniatures

The cat-and-keyboard and orbiting-planet vector miniatures are original artwork created for this profile. No Sweezy files, character designs, or animation frames are included. Sweezy (https://sweezy-cursors.com/) was a general reference for playful personalization, not an asset source.

Animation is self-contained CSS inside SVG image assets, with a static fallback and prefers-reduced-motion handling. There is no JavaScript, tracking, external image request, cursor override, or browser extension.

## Snapshot-linked ornaments

- Each filled miniature star represents 50 public Stars, capped at five (250). It is not a quality rating.
- Each bookshelf book represents one public repository, capped at 12.
- The fork diagram is decorative, not an event stream.
- The delivery robot's rail shows the remainder toward the next 1,000 release-asset downloads. Its bobbing is decorative, not live transfers.
- The paper plane marks the centre of the largest primary-language segment, using the existing deterministic language sort.
- The contribution rover marks the latest active calendar week. It does not claim current online activity or alter any contribution intensity cells.

All positions and counts derive from the last successful snapshot; original numbers remain unchanged. Reduced-motion preferences stop all CSS animation.

## Project scenes and relative interest

Each featured project has an original miniature: an Android-like research robot, a firefly light jar, a sunrise sprout, or a token terminal. Scene choice expresses subject matter, not popularity. The slim bar beneath each Stars label equals that project's cumulative public Stars divided by the maximum among featured projects. Zero remains empty; an all-zero group remains empty. This is not traffic, recent growth, activity, or a verified trend. The scenes do not cover the text or change the repository link targets.
